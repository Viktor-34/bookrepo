## 🔧 Технические детали (кратко)

### Stack:
- **Frontend:** Next.js 14 + TypeScript + React
- **Backend:** tRPC + Next.js API
- **Database:** PostgreSQL + Drizzle ORM
- **Search:** Meilisearch
- **AI:** OpenAI / Ollama
- **Deploy:** Docker + Docker Compose

### Что будем добавлять:

**CSV Import:**
```
POST /api/trpc/bookmarks.importCSV
Input: CSV файл с колонками: url, tags, notes
Output: { total, queued, failed }
```

**UI:**

## ❓ FAQ

**Q: Hoarder уже умеет сохранять Twitter посты?**
A: Да! Через расширение ты просто кликаешь кнопку на странице поста, и он сохраняется с изображениями.

**Q: Нужно ли платить за AI?**
A: Нет, можешь использовать бесплатный Ollama локально или отключить AI теги.

**Q: Можно ли сохранять посты без расширения?**
A: Да, есть веб-интерфейс, mobile apps, и скоро будет CSV импорт.

**Q: Как часто обновлять форк с upstream?**
A: Периодически, когда выходят новые фичи. Hoarder активно развивается.

**Q: Сложно ли поддерживать форк?**
A: Нет, если минимально модифицировать код. CSV импорт - изолированная фича.
